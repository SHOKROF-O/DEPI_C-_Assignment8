# Assignment 4 - OOP

C# - ASP.Net Course

## First Project - Point3D.cs

- Constructors chained (default -> 2 params -> 3 params).
- ToString() produces "Point Coordinates: (X, Y, Z)".
- Implements IComparable (sort by X then Y) and ICloneable.
- Reading points from user uses Parse, TryParse and Convert.

## Second Project - Maths.cs

- Static class with Add, Subtract, Multiply, Divide.
- No need to create an instance to call the methods.

## Third Project - Duration.cs

- Hours, Minutes, Seconds attributes.
- Constructor from (hours, minutes, seconds) and constructor from total seconds.
- Overrides ToString, Equals and GetHashCode.

## Program.cs

Runs all three projects one after another.
